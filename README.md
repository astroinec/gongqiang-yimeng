# 宫墙一梦

《甄嬛传》IP 粉丝向互动文字游戏。玩家通过隐藏属性、人物关系和特殊选择，解锁不同命运、动态尾声和宫墙轶闻。

## 直接游玩

解压后双击 `index.html` 即可在浏览器中运行，不需要安装依赖或联网。

如果浏览器对本地文件有限制，可在本目录启动静态服务器：

```bash
python3 -m http.server 8765
```

然后打开：`http://localhost:8765`

## 当前内容

- 横版 16:9 优先，兼容手机竖屏
- 29 个剧情节点、11 个扩展场景铺垫
- 6 类大结局、动态尾声
- 7 个隐藏全局属性、8 个角色关系值
- 12 个成就/宫墙轶闻
- 自动存档、继续游戏、命运图鉴
- 内置 5 张场景背景与 5 位角色立绘（甄嬛/眉庄/陵容/皇后/华妃），未覆盖的角色自动回退为 CSS 剪影
- 支持无代码替换美术：放入同名文件即可覆盖

## 文件

- `index.html`：页面入口
- `styles.css`：横竖屏 UI 与占位美术
- `game.js`：剧情、隐藏数值、关系、结局和成就
- `assets/manifest.js`：正式图片资源映射
- `assets/README.txt`：图片命名和接入说明
- `AI美术提示词-场景与立绘.md`：原剧妆造还原型生图提示词

## 更换正式美术

把背景和立绘放入 `assets/backgrounds/`、`assets/characters/`，再在 `assets/manifest.js` 登记路径。没有登记或图片不存在时，游戏会自动保留 CSS 剪影，不影响运行。
